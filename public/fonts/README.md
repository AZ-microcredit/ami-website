# Bundled website fonts

AMI Sans: Arimo variable, normal and italic, Latin, weights 400 to 700.
AMI Serif: Tinos, Latin, regular/bold and normal/italic.

Source: @fontsource-variable/arimo 5.3.0 and @fontsource/tinos 5.3.0 from the npm registry. Original licenses are included beside the font files. These files are served locally; no Google Fonts requests or operating-system font installations are required.
